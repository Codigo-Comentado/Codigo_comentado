## 🎯 Objetivo

Este documento foi criado para orientar a forma de estudo dentro do Código Comentado.

Mais do que disponibilizar exemplos de código, o nosso objetivo é oferecer um caminho estruturado de aprendizado, permitindo que cada estudante evolua de forma consistente, compreendendo não apenas **como escrever código**, mas também **por que cada conceito existe**.

## 📖 Método de estudo recomendado

Sugerimos estudar um conceito por vez. Para cada arquivo:

| Etapa | O que fazer                                                                                                                |
|:---:|----------------------------------------------------------------------------------------------------------------------------|
| 1️⃣ | **Leia a explicação completa** - antes de executar o código, procure entender o problema que aquele conceito resolve.      |
| 2️⃣ | **Analise o código** - leia cada comentário e tente compreender a intenção de cada linha.                                  |
| 3️⃣ | **Execute o exemplo** - compile, execute, observe o comportamento e faça pequenos experimentos.                            |
| 4️⃣ | **Resolva o exercício** - todo conceito deve ser praticado; aprender programação exige repetição.                          |
| 5️⃣ | **Revise** - após alguns dias, retorne ao conteúdo; a revisão fortalece a memória e facilita a conexão entre os conceitos. |

## 🎯 Não tenha pressa

Não existe vantagem em concluir rapidamente todos os módulos.

O objetivo não é terminar o roadmap. O objetivo é compreender cada conceito.

> É preferível dominar dez assuntos do que conhecer superficialmente cem.

## 🤝 Aprenda ensinando

O Código Comentado acredita que ensinar é uma das formas mais eficientes de aprender.

Quando você sentir segurança em determinado assunto:

- Contribua com melhorias
- Proponha novos exemplos
- Corrija explicações
- Compartilhe analogias
  Ao ensinar outra pessoa, você fortalece o próprio conhecimento.

## 🎓 Nosso compromisso

O Código Comentado não busca apenas ensinar sintaxe.

O Nosso objetivo é ajudar você a desenvolver raciocínio lógico, compreender os fundamentos da programação e construir conhecimento duradouro.

Mais importante do que decorar comandos é entender os princípios que fazem o software funcionar.

Acreditamos que aprender programação é uma jornada contínua. Esperamos que este projeto acompanhe você durante essa jornada.
