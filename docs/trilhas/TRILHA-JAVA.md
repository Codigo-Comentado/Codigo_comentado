# 🚀 Trilha Java - Do Zero à Engenharia de Software

**Código Comentado**
*Aprender Programação Ensinando Programação*
 
---

## 📖 Sobre esta trilha

Esta trilha foi criada para guiar estudantes desde os **fundamentos da programação** até o **desenvolvimento de aplicações profissionais** utilizando Java.

## 📋 Pré-requisitos

| Requisito | Status |
|---|---|
| Conhecimento prévio | Não é necessário |
| Curiosidade e disposição para praticar | ✅ Essencial |

## 🟢 Nível 1 - Fundamentos da Programação

**Objetivo:** aprender os conceitos fundamentais que existem em qualquer linguagem.

**Conteúdos**
- Algoritmos
- Variáveis
- Tipos de dados
- Operadores
- Condicionais
- Repetições
- Funções
  **Ao finalizar você será capaz de:**
- ✅ Resolver problemas usando lógica
- ✅ Criar pequenos algoritmos
- ✅ Entender a base de qualquer linguagem
> 💻 **Projeto sugerido:** Calculadora de terminal
 
---

## 🟢 Nível 2 - Fundamentos do Java

**Objetivo:** conhecer a linguagem Java e sua estrutura.

**Conteúdos**
- História do Java
- JVM
- JDK
- Primeiro programa
- Sintaxe
- Variáveis
- Tipos primitivos
- Strings
- Entrada e saída
> 💻 **Projeto sugerido:** Sistema de cadastro simples

## 🟡 Nível 3 - Programação Orientada a Objetos

**Conteúdos**

- Métodos
- Encapsulamento
- Associação
- Composição
- Herança
- Polimorfismo
- Interfaces
> 💻 **Projeto sugerido:** Sistema bancário
