# LICENCIAMENTO — CÓDIGO COMENTADO

Copyright © 2026 Código Comentado

O Código Comentado é um projeto educacional open source criado com o propósito de tornar o aprendizado de programação mais acessível, prático e colaborativo.

Nossa política de licenciamento parte de um princípio:

> **O conhecimento deve permanecer aberto. A comunidade deve ser reconhecida. A identidade do Código Comentado deve ser preservada.**

Este documento define as condições aplicáveis aos diferentes tipos de conteúdo, código e elementos de identidade presentes nos repositórios do Código Comentado.

---

## 1. 📚 CONTEÚDO EDUCACIONAL

Salvo indicação específica em contrário, os conteúdos educacionais não classificados como código-fonte são disponibilizados sob:

**Creative Commons Attribution-ShareAlike 4.0 International — CC BY-SA 4.0**

Isso inclui, entre outros:

* roadmaps;
* trilhas de aprendizagem;
* guias de estudo;
* documentação pedagógica;
* explicações conceituais;
* materiais escritos em Markdown;
* textos educacionais;
* diagramas especificamente identificados como conteúdo aberto;
* outros materiais didáticos não classificados como código-fonte.

### Você pode

* compartilhar;
* copiar;
* redistribuir;
* adaptar;
* transformar;
* criar materiais derivados;
* utilizar o conteúdo inclusive para fins comerciais.

### Sob as seguintes condições

**Atribuição:** deve ser dado o crédito apropriado ao Código Comentado e aos autores/contribuidores quando aplicável, além do cumprimento das demais exigências da CC BY-SA 4.0.

**CompartilhaIgual:** caso o material seja remixado, transformado ou adaptado, a contribuição resultante deverá ser distribuída sob a mesma licença ou uma licença considerada compatível pela Creative Commons.

## 2. 💻 CÓDIGO-FONTE EDUCACIONAL

Salvo indicação específica em contrário, arquivos de código-fonte utilizados como aulas, demonstrações, exercícios e exemplos executáveis são disponibilizados sob:

**GNU General Public License v3.0 — GPL-3.0**

Isso inclui, entre outros:

* arquivos `.java`;
* arquivos `.py`;
* código em outras linguagens;
* exemplos executáveis;
* implementações educacionais;
* projetos de demonstração identificados como parte das aulas.

A GPL-3.0 permite utilizar, estudar, modificar e redistribuir o código nos termos estabelecidos pela própria licença.

O texto oficial e integral da GNU GPL v3.0 está disponível em:

https://www.gnu.org/licenses/gpl-3.0.html

### Observação sobre arquivos educacionais

Os arquivos de aula do Código Comentado podem conter código-fonte e extensos comentários pedagógicos no mesmo arquivo.

Quando um arquivo de código-fonte for disponibilizado sob GPL-3.0, o arquivo como um todo será tratado sob essa licença, salvo indicação explícita em contrário.

Isso evita ambiguidades entre o código executável e os comentários educacionais incorporados diretamente ao código.

A existência deste documento não substitui uma licença específica declarada por outro repositório do ecossistema Código Comentado.

## 4. 🎨 MARCA E IDENTIDADE

As licenças aplicáveis ao conteúdo e ao código-fonte **não concedem automaticamente autorização para utilização da identidade oficial do Código Comentado**.

Salvo autorização expressa, não estão incluídos nas licenças abertas descritas neste documento:

* nome **Código Comentado**;
* logotipo oficial;
* mascote **Codee**;
* representações e ilustrações oficiais do Codee;
* identidade visual;
* elementos gráficos oficiais;
* nomes comerciais;
* outros sinais distintivos associados ao projeto.

A utilização de código ou conteúdo disponibilizado pelo Código Comentado não implica autorização para apresentar outro projeto, produto ou serviço como oficial, afiliado, patrocinado ou aprovado pelo Código Comentado.

## 5. 🤖 MASCOTE CODEE

O **Codee** é um elemento da identidade oficial do Código Comentado.

Sua presença em repositórios, documentação, redes sociais, vídeos, imagens ou outros materiais não significa que o mascote esteja automaticamente submetido às licenças aplicáveis ao código-fonte ou ao conteúdo educacional.

O uso do Codee fora dos materiais oficiais do Código Comentado poderá exigir autorização específica.

---

## 6. 🔀 FORKS E PROJETOS DERIVADOS

Forks, estudos, adaptações e projetos derivados são bem-vindos quando realizados de acordo com as respectivas licenças.

Um projeto derivado pode utilizar materiais disponibilizados pelo Código Comentado nos limites das licenças aplicáveis.

Entretanto, isso não concede automaticamente o direito de utilizar nome, logotipo, mascote ou identidade visual de maneira que possa causar confusão com o projeto oficial.

Projetos independentes derivados do Código Comentado devem ser apresentados de maneira suficientemente distinta.

É permitido realizar atribuições verdadeiras, como:

> Baseado em conteúdo do projeto Código Comentado.

Isso não significa que o projeto derivado seja oficial ou possua vínculo institucional com o Código Comentado.

## 7. 👥 CONTRIBUIÇÕES

Ao enviar uma contribuição para o Código Comentado, o colaborador declara que possui os direitos necessários sobre o material submetido e concorda que sua contribuição seja disponibilizada sob a licença aplicável ao conteúdo ou código para o qual está contribuindo.

Isso pode incluir:

* código;
* aulas;
* documentação;
* exemplos;
* exercícios;
* traduções;
* correções;
* roadmaps;
* trilhas;
* materiais educacionais.

De forma geral:

* código-fonte educacional → **GPL-3.0**;
* roadmaps, trilhas e conteúdo educacional não classificado como código → **CC BY-SA 4.0**;
* software e plataforma → licença estabelecida pelo respectivo repositório.

O colaborador mantém os direitos autorais que possuir sobre sua contribuição, disponibilizando-a nos termos da licença aplicável.

Não devem ser enviados materiais de terceiros sem autorização ou licença compatível com sua utilização pelo Código Comentado.
